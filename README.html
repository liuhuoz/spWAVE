spWAVE

Spatial Whole Area Vector Estimation (spWAVE) is design to estimate the ligand receptor spatial interference based on vector field superposition principle.

Installation

Dependency

Require Seurat >= 5.0, because the data structure changed after 5.0, This package use the new ‘layers’ structure to access data, which is not compatible with Seurat < 5.0. And we recomannd Seurat >=5.1.0, due to a better compatible with new ST techniques, escpecially for the HD single-cell ST.

Install

Right now, it is a non-open source package, even not published on github, so please download the .zip file and install it from local.

devtools::install_local("spWAVE.zip")
